FAQ

C'est quoi Bazo ?

Un assistant pour les voyageurs TER : alertes, suivi des trajets, PDF pour la Garantie Fiabilité SNCF.

Comment m'inscrire ?

Ouvre @SbazoTrain_bot → /start → configure tes gares et créneaux.

L'app web, c'est quoi ?

Alternative mobile sans installation store : /app/. Token API via /token en message privé sur Telegram.

Mes données ?

Export et suppression via l'app web (onglet Compte) ou contact admin. Voir la politique de confidentialité.
